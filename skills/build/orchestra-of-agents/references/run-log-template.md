# 実行ログテンプレート

クリーンアップ時に `/tmp/orchestra-{team-name}/{YYYY-MM-DD}-{task-slug}.md` に保存する。

```markdown
# orchestra 実行ログ: {task-slug}

## メタデータ
- 日付: {YYYY-MM-DD}
- プロジェクト: {プロジェクト名}
- 総ファイル数: {N}
- 構成: {標準 / 最小}
- チーム構成: {メンバー一覧と担当ファイル数}
- 修正ループ: {N}回

## ストール監視
- 発動回数: {N}回（発動なしなら 0）
- 対象メンバー: {impl-1 / tester 等}
- 発動タイミング: {Wave N 切り替え時 / スモーク報告待ち 等}
- 解消手段: {SendMessage 再送 / TaskList 再割当 / conductor 介入 等}

## 発見された問題
{重大度ラベル（P1/P2/P3）+ 現象 + 根本原因 + 影響}

## 改善提案
{適用済み / 未適用に分けて記載}
```
