# シークレットパターン
# git commit/push 前に自動チェックされる
# 空行とコメント行(#)は無視される
# 正規表現が使用可能

# 個人情報（自分のユーザー名やホームディレクトリに書き換えてください）
# your-github-username
# your\.name
# /Users/your\.name

# 組織情報（自分の組織名に書き換えてください）
# your-org-name
# your-org\.co\.jp

# プロジェクト固有（公開したくないプロジェクト名があれば追加）
# internal-project-name

# シークレットプレフィックス（実キー形状: プレフィックス + 本体。プレフィックス単体の文書記述は誤検出しない）
